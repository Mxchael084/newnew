# Rupture Reborn (Forge 1.21.11)

ClickGUI öffnen: Rechte Shift-Taste, Einfügen oder K (in einer Welt, ohne offenes Menü).
Linksklick auf ein Modul = an/aus, Rechtsklick = Einstellungen (Slider, Tastenbelegung).
Kampf-Module laufen nur in lokalen Welten (Einzelspieler/LAN).
Anzeige der aktiven Module erscheint über der Hotbar.
